Resource Group
----------------
while creating rg frm portal mandatory parameters are
a. Subscription ID
b. Resource grp name
c.Location - which is nothing but "region" in portal.
d. tags - optional
then review and create

Storage Account
----------------
a. Subscription ID
b. resource grp name
c. region in portal == location in terraform
d. storage account name (unique name )
e. Performance in portal == Account Tier for terraform ( Standard or Premium)
f. Redudancy in portal == account replication type in terraform (LRS,GRS, ZRS, RAGRS, GZRS, RA-GZRS)

Key Vault
------------
a. Subscription ID
b. Resource grp name
c. Key Vault name (unique)
d. region in portal == location in terraform
e. pricing tier in portal == sku_name in terraform (standard, premium)
f. days to retain deleted vaults in portal == soft_delete_retention_days in script ( 7 to 90 days)
